PROBLEM #6: FIND PIVOT INDEX 🚀

Problem Name: Find Pivot Index

Category: Arrays & Strings
Pattern: Prefix Sum
Difficulty: EASY

PROBLEM DESCRIPTION:

Given an array of integers nums, calculate the pivot index of this array.

The pivot index is the index where:

Sum of all elements to the LEFT = Sum of all elements to the RIGHT

Return the leftmost pivot index. If no such index exists, return -1.


EXAMPLES:
Example 1:
Input: nums = [1,7,3,6,5,6]
Output: 3
Explanation:
  Left sum of index 3 = 1+7+3 = 11
  Right sum of index 3 = 5+6 = 11
  ✓ Pivot found at index 3

Example 2:
Input: nums = [1,2,3]
Output: -1
Explanation:
  Index 0: left=0, right=5 (not equal)
  Index 1: left=1, right=3 (not equal)
  Index 2: left=3, right=0 (not equal)
  ✗ No pivot index

Example 3:
Input: nums = [2,1,-1]
Output: 0
Explanation:
  Index 0: left=0 (no elements), right=-1+1=0
  ✓ Pivot at index 0

Example 4:
Input: nums = [0,0,0,0,0,0]
Output: 0 or 1 or 2 or 3 or 4 or 5
Explanation:
  All indices have left=0, right=0
  Return leftmost = 0 ✓
