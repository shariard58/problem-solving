PROBLEM #8: RUNNING SUM OF 1D ARRAY 🚀

Problem Name: Running Sum of 1d Array

Difficulty: EASY | Pattern: Prefix Sum

What: Return array of running sum. At each index i = sum of all elements from 0 to i.

Examples:

Input: nums = [1,2,3,4]
Output: [1,3,6,10]
Explanation:
  Index 0: 1
  Index 1: 1+2 = 3
  Index 2: 1+2+3 = 6
  Index 3: 1+2+3+4 = 10

Input: nums = [3,1,2,10,1]
Output: [3,4,6,16,17]

Input: nums = [1,-2,3,4,-5]
Output: [1,-1,2,6,1]

Constraints:

1 <= nums.length <= 1000
-10^6 <= nums[i] <= 10^6

Expected:

⏱️ Time: O(n)
💾 Space: O(n) - for output array
