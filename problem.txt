Problem Name: First Unique Character in a String

What: Find index of first character that appears ONLY ONCE
      If none exists → return -1

Example 1: s = "leetcode" → 0 (l appears once)
Example 2: s = "loveleetcode" → 2 (v is first unique char)
Example 3: s = "aabb" → -1 (no unique chars)

Pattern: Hash Map / Frequency
Expected Complexity: O(n) time, O(1) space
