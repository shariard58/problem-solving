PROBLEM 1: TWO SUM 🎯

Problem Name: Two Sum

What is it?
Given an array and a target number, find the indices of two numbers that add up to the target.

Examples:

Example 1:
Input: nums = [2, 7, 11, 15], target = 9
Output: [0, 1]
Explanation: nums[0] + nums[1] = 2 + 7 = 9

Example 2:
Input: nums = [3, 2, 4], target = 6
Output: [1, 2]

Example 3:
Input: nums = [3, 3], target = 6
Output: [0, 1]

Expected Complexity:

⏱️ Time: O(n) - best case
💾 Space: O(n) - acceptable
