PROBLEM #7: INTERSECTION OF TWO ARRAYS 🚀

Problem Name: Intersection of Two Arrays

Difficulty: EASY | Pattern: Hash Map/Set

What: Find common elements between two arrays (each element appears only once in result)

EXAMPLES:
Input: nums1 = [1,2,2,1], nums2 = [2,2]
Output: [2]

Input: nums1 = [4,9,5], nums2 = [9,4,9,8,4]
Output: [4,9]

Input: nums1 = [1,2,3], nums2 = [4,5,6]
Output: []
CONSTRAINTS:
1 <= nums1.length, nums2.length <= 1000
0 <= nums1[i], nums2[i] <= 1000
EXPECTED COMPLEXITY:
⏱️ Time: O(n + m)
💾 Space: O(min(n,m))
