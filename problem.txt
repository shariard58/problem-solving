PROBLEM #4: MOVE ZEROES 🚀

Problem Name: Move Zeroes

What is it?
Given an array, move all zeros to the end while maintaining the relative order of non-zero elements. Do it in-place (don't create new array).

Examples:

Example 1:
Input: nums = [0, 1, 0, 3, 12]
Output: [1, 3, 12, 0, 0]
Explanation: Zeros moved to end, order of non-zeros maintained ✓

Example 2:
Input: nums = [0]
Output: [0]
Explanation: Only one zero ✓

Example 3:
Input: nums = [1, 2, 3]
Output: [1, 2, 3]
Explanation: No zeros, array unchanged ✓

Example 4:
Input: nums = [0, 0, 1]
Output: [1, 0, 0]
