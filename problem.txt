PROBLEM #4: VALID ANAGRAM 🚀

Problem Name: Valid Anagram

What is it?
Check if two strings are anagrams. Two words are anagrams if they contain the same characters with the same frequencies, just in different order.

Examples:

Example 1:
Input: s = "anagram", t = "nagaram"
Output: true
Explanation: Both have same chars: a(3), n(1), g(1), r(1), m(1) ✓

Example 2:
Input: s = "rat", t = "car"
Output: false
Explanation: Different characters ✗

Example 3:
Input: s = "ab", t = "ba"
Output: true
Explanation: Same chars, different order ✓

Example 4:
Input: s = "a", t = "ab"
Output: false
Explanation: Different lengths
